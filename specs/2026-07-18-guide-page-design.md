# 가이드 페이지 신설 설계

- 날짜: 2026-07-18
- 상태: 승인됨
- 범위: 플레이북의 동작 전과정을 누구나 이해할 수 있게 설명하는 "가이드" 페이지를 신설하고, 상단 탭바로 사이트 최상단에 노출한다. 4개 언어(ko/en/zh/ja).

## 확정된 결정

| 결정 | 선택 | 근거 |
|------|------|------|
| 상단 표기 방식 | Material `navigation.tabs` 활성화 (상단 가로 탭바) | "사이트 상단에 함께 표기" 요구에 가장 부합, 모바일 대응 |
| 콘텐츠 구성 | 생애주기 스토리 (단일 흐름 + 단계별 설명) | "전과정을 누구나 이해" 목표 — 구성요소 사전식은 기각 |
| nav 위치 | 홈 다음 2번째 항목 `가이드: guide.md` | 첫 방문자 동선 |

## 1. 새 페이지 `docs/guide.md`

구조 (위→아래):

1. H1 `# 가이드 — 이 Playbook은 어떻게 동작하는가`
2. 메타데이터 라인 (staleness 계약 필수): `_최종 갱신: 2026-07 · owner: comeddy · volatility: 낮음(프로세스 페이지 — 파이프라인 변경 시에만 갱신)_` + `[← index로](index.md)`
3. L0 TL;DR: 이 사이트는 뉴스 아카이브가 아니라 **검증 파이프라인** — 모든 항목은 관문을 통과해야 본문에 실린다는 한 문단
4. **한눈에 보는 전과정**: ASCII 다이어그램 1개(코드 블록) — 후보 발견(주간 자동 스캔·제보) → Radar 대기열(미검증 `[4]`) → 1차 출처 검증 → THE FILTER(4중 2) → 필러 본문 승격 → staleness 배지(신선도 감시) → 4개 언어 동기화 → CI 배포
5. 단계별 설명 7개 H2 섹션 (각 3~6문장, 비전문가 언어):
   - ① 어떻게 만들어졌나 — 마스터 프롬프트 스펙, 페이지별 적대적 검증
   - ② 무엇이 실리고 무엇이 걸러지나 — THE FILTER(ⓐⓑⓒⓓ 중 2), 성숙도 라벨, 출처 등급 [1]~[4]
   - ③ Radar와 주간 자동 스캔 — 매주 월 02:00 UTC 자동 갱신, 유입분은 전부 미검증 표시, 고객 제안 사용 금지
   - ④ 검증과 승격 — 1차 출처 확인·승격 판단은 사람(owner) 몫, 자동화는 대기열까지만
   - ⑤ 신선도 자동 감시 — volatility별 기준(1/3/6개월) 초과 시 ⏳ 배지 자동 주입, 주간 재배포
   - ⑥ 4개 언어 동기화 — 한국어가 원본, ko_hash로 표류 감지, 번역은 파생물
   - ⑦ 배포 파이프라인 — push 시 strict 빌드 게이트(앵커·링크 검증) 통과분만 배포
6. **역할별 안내** H2: 읽는 사람(라벨 읽는 법 링크) / 제보하는 사람(승격 파이프라인 링크) / owner(maintenance 링크)
7. 기존 페이지로의 링크는 상대 링크(`index.md`, `maintenance.md#...` 등) — 앵커는 실측 확인

## 2. mkdocs.yml 변경

- `theme.features`에 `navigation.tabs` 추가 (상단 탭바 — 외관 변경 의도됨)
- `nav`의 홈 다음에 `- 가이드: guide.md` 삽입
- `plugins.i18n.languages[en/zh/ja].nav_translations`에 `가이드: Guide` / `가이드: 指南` / `가이드: ガイド` 추가

## 3. 번역 (en/zh/ja)

- `docs/guide.en.md` / `guide.zh.md` / `guide.ja.md` — frontmatter `ko_hash`, `i18n/glossary.md` 준수, heading 번역 시 본문 앵커 동시 갱신(빌드 산출물 실측)
- 기존 확립 관례: 메타데이터 라벨만 번역·값 유지, 배지·이모지·구조 보존

## 4. 검증 계획

- `python3 scripts/check_staleness.py --check` — 10페이지 전부 메타데이터 OK (guide 포함, exit 0)
- `python3 scripts/check_translation_sync.py` — **비동기 0/30** (9→10페이지)
- `mkdocs build --strict` exit 0 + 산출물에서 탭바 마크업 확인
- push → CI 성공 → 라이브 4개 언어 `/guide/` 200 + 탭바 노출 확인
