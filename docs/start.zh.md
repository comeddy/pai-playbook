# 开始 — 业务适配、ROI 与试点批准

_最后更新: 2026-09 · owner: Youngjin · volatility: 中_

**L0 TL;DR**: 先定义要改善的业务和当前表现。比较现有自动化、商用方案及系统集成商（SI）[^si]，只有需要学习时才选择数据、仿真或 VLA 路径。客户与 AWS 员工共同填写本页。

## 按角色选择路径 { #roles }

| 角色 | 先阅读 | 会议产出 |
|---|---|---|
| 客户决策者 | 本页 → [高管简报](exec.md) | 一个任务、费用上限、推进/暂停标准 |
| 客户技术团队 | [执行路径](execution.md) → 对应支柱 → [运营与恢复](operations.md) | 前置条件、实验计划、负责人 |
| AWS 员工 | [对话指南](exec-guide.md) → [决策](decisions.md) | 需求问题、替代方案、支持及合作伙伴分工 |

员工指南同样公开。不要在本站记录内部联系方式或客户机密材料。

## 业务适配 — 首次会议的八个问题 { #fit }

| 问题 | 与客户填写 |
|---|---|
| 要改善什么任务？ | 用一句话描述工序、物体、环境、开始及完成条件 |
| 目前表现如何？ | 每小时完成量、周期、失败/返工率、人工介入次数 |
| 现有方式为何不足？ | 比较规则自动化、控制改进、商用产品和 SI 报价 |
| 哪些变化需要学习？ | 物体、光照、布局、指令变化及实际频率 |
| 已有哪些资源？ | 机器人、传感器、日志、演示、CAD、使用权、人员 |
| 现场限制是什么？ | 人员接近、断网、延迟、功率、数据处理国家 |
| 谁负责运行和恢复？ | 现场、机器人/SI、ML、云的实名负责人 |
| 什么情况下停止？ | 费用/时间上限、相对基线的最小改善、安全及恢复条件 |

**推进**：任务和基线可测量，有改善假设、实验资源及运营负责人。**暂停**：使用权、现场责任或费用上限未明确。**选择替代方案**：商用产品或现有自动化以更低总成本满足需求。在 [Build vs Buy](decisions.md#4-build-vs-buy基础模型) 中记录选择。

## 总成本与 ROI — 不只看 GPU 报价 { #roi }

分别计算**低/基准/高情景**。未知费用写“待报价”，不要填零。复制[预算 CSV](assets/pilot-budget.csv)，填写数量、单价及周期（USD 表单，并非价目表）。

| 费用类别 | 包含项目 |
|---|---|
| 初始固定费用 | 机器人、夹爪、传感器、安装/SI、数据采集清洗、环境制作、安全审查验证 |
| 实验变动费用 | GPU 实例小时、存储/传输/日志、模型/API、失败重试、工程人员 |
| 运营经常费用 | 维护、零部件、监控、人工介入、推理连接、再训练及现场复核 |
| 预期收益 | 实际减少的返工及停机、可兑现的吞吐量价值、可重新安排的人力时间 |

`期间净收益 = 期间收益 − 期间运营费用`

`回收期 = 初始投资 / 月净收益`（仅在月净收益为正时计算）

`期间 ROI = (期间收益 − 初始投资 − 期间运营费用) / (初始投资 + 期间运营费用)`

仿真可降低实验费用，但不消除环境制作、校准及实机验证费用。不要重复计算同一收益的生产率提升与人工节省。记录估价和收益假设的来源及确认日期。

## 试点批准卡 { #pilot }

复制到项目文档。周期、演示数量、成功率由客户场景约定，不是通用承诺。

```text
任务 / 排除范围:
现有方式 / 替代方案 / 基线测量期间:
目标指标 / 最小改善 / 测量条件:
评估样本数 / 重复运行 / 未学习环境:
数据、代码、权重使用权:
负责人: 现场 / 机器人-SI / ML / 云 / 安全:
费用: 初始 / 实验 / 月运营 / 低-基准-高:
上限: 最大支出 / 截止日 / 延长批准人:
停止: 未达标 / 超预算 / 安全恢复测试失败:
下一阶段所需证据及批准人:
```

**阶段条件**：建立基线 → [隔离实验](execution.md) → [有限现场验证](operations.md) → 扩大运营。每阶段审查指标、费用、人工介入及恢复结果。技术 GA 或通用“12~24 个月”预测不构成进入下一阶段的批准。

**➡️ 后续行动**：下次客户会议填写一张卡，决定推进、暂停或替代方案。推进时只选择适合当前瓶颈的一条[执行路径](execution.md)。

<!-- 용어 각주 -->
[^si]: **SI（System Integrator，系统集成商）** — 在客户现场集成机器人、设备、控制和软件的服务商。云服务支持与工作站集成、安全责任应分别指定。
